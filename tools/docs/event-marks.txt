# Hand marks for events: Kupfermeister's verdicts, which the generated list (src/main/resources/lullaby/events.txt)
# can't know. Read by tools/docs/Docs.java; a name that isn't in events.txt stops the docs build.
# One event per line: the name, then its marks (space-separated); "#" starts a comment.
#   tested  stress tested and measured: its dot gets its color (copper: on{ } can change something, teal: read only).
#           Until then every event has a gray dot ("there, not tested yet").
#   busy    fires very often (many times per tick on a busy server): every handler runs on each one, so keep it short
#   thread  Paper may fire it off the main thread: Lullaby skips it then (the console says so once). Events Paper
#           always fires off the main thread (Async...) can't be used at all; events.txt marks those itself.
