  ## Test server
  Never test on the server your players use.
  1. Install Java 25. Download Paper for the Minecraft version at the top of the side list, put it in an empty folder as `paper.jar`.
  2. Start it with `java -Xms2G -Xmx2G -jar paper.jar nogui`. Set `eula=true` in `eula.txt`, start again.
  3. Build Lullaby (`gradlew build`, jar in `build/libs`), put the jar in `plugins`, restart. This makes the folder `plugins/lullaby`.
  4. Join `localhost`, then type `op YourName` in the server window. Ops see script errors in chat.

  Scripts go in `plugins/lullaby/scripts`. Every `.lua` file there loads; a name starting with `--` switches a file or folder off. Settings are in `plugins/lullaby/config.lua`.

  ## Editor
  VS Code (free) then suggests Lullaby names while you type, shows what they do, and underlines mistakes before you reload.
  1. **Install VS Code** from code.visualstudio.com and open it.
  2. **Add Lua.** Click the four squares on the far left (`Ctrl+Shift+X`), search `Lua`, install **Lua** by **sumneko**.
  3. **Open the folder.** **File → Open Folder…**, pick `plugins/lullaby` in your server folder. If asked whether you trust the authors, click **Yes**.
  4. **Add the name list.** [Download lullaby.d.lua](lullaby.d.lua); your browser puts it in your **Downloads** folder. Move it into `plugins/lullaby`, right next to `config.lua`, **not** into `scripts` (a file in `scripts` would run as a script). The easy way: drag it from Downloads onto the empty space in VS Code's left side, below the files. Only the editor reads it; Lullaby never runs it.
  5. **Tell VS Code which Lua.** Right-click the empty space on the left, **New File…**, name it `.luarc.json` (dot in front), paste `{ "runtime.version": "LuaJIT" }`, save with `Ctrl+S`. Without it, some correct code is marked wrong.

  The left side now shows `scripts`, `.luarc.json`, `config.lua`, `lullaby.d.lua`. To check: in `scripts` make `test.lua`, type `mess` and a list pops up with `message`; point at it to see its description. Delete `test.lua` afterwards, or the next reload runs it. Nothing pops up? `Ctrl+Shift+P`, `Reload Window`.

  > After a Lullaby update, download `lullaby.d.lua` again and replace the old one.

id: lua
name: Lua basics
kind: guide
group: Guide
also: guide_lua guide_variables guide_if guide_loops comments values nil true false numbers strings and or not local tables methods if then else elseif while repeat until for in do break goto function return end varargs closures error string_lib table_lib math_lib metatables locked io os ffi debug require
words: lua syntax grammar basics assert check select unpack tonumber tostring type next load loadstring rawget rawset pcall xpcall gsub gmatch byte char coroutine bit band pattern escape operator order variable local value table list number text string nil true false if then else elseif condition loop for while repeat until forever ipairs pairs break goto continue function return comment operator equal join length string table math random floor format insert remove sort concat metatable setmetatable
lead: Everything Lua has, on one page: every piece of grammar and every built-in function scripts can use, each with a hint. Lullaby's own functions (message{ }, wait( ), ...) have their own pages in the side list.
text:
  ## Writing code
  - A block starts with a word and closes with `end`: `if ... then` ... `end`. Every `if`, `for`, `while`, `do` and `function` needs its own `end`; a missing one is the most common error (it points to the end of the file).
  - Indent the inside by two spaces so you see what belongs where. Lua ignores spaces and line breaks; you won't.
  - Capitals matter: `Message` is not `message`.
  - `--` starts a comment to the end of the line, `--[[ ... ]]` one over many lines. Lua skips it; write notes there.
  - `;` may end a statement but is never needed. `do ... end` makes a block of its own, so its `local` variables vanish after it.

  ## Values
  - `nil`: nothing. Unset variables and missing fields are `nil`.
  - `true`, `false`: yes and no.
  - Numbers: `42`, `-3`, `3.14`, `1e3` (1000), `0xFF` (255). Whole numbers and decimals are one kind.
  - Text: `"hi"` or `'hi'`; `[[...]]` over many lines, as written. Inside quotes: `\n` new line, `\t` tab, `\"` and `\'` a quote, `\\` a backslash.
  - Tables `{ }` and functions are values too; see below.

  ## Variables
  ```
  local coins = 10            -- make a variable and set it
  coins = coins + 5           -- change it (no "local" again)
  local first, second = 1, 2 -- several at once
  first, second = second, first -- swap
  local nothing                     -- made, still nil
  ```
  Always write `local` the first time: the variable then belongs to the block it is in (file, function, if, loop). Without `local` it is a global of this file.

  ## Operators
  - Math: `+ - * /`, `%` remainder (`7 % 2` is 1), `^` power, `-value` minus. `7 / 2` is `3.5`; whole division is `math.floor(7 / 2)`.
  - Compare: `==` equal, `~=` not equal, `< > <= >=`. **One `=` stores, two compare**: `if value = 5` is an error.
  - Logic: `and`, `or`, `not`. Only `nil` and `false` count as false; `0` and `""` are true. `value or 5` gives value, or 5 when value is nil: a default. `check and yes or no`: yes if check, else no.
  - Text: `..` joins (`"a" .. 1` is `"a1"`), `#` is the length of a text or list.
  - Order: `^`, then `not # -`, then `* / %`, then `+ -`, then `..`, then compares, then `and`, then `or`. Use `( )` when unsure.

  ## Tables
  ```
  local list = { "a", "b", "c" }     -- a list, counted from 1
  print(list[1], #list)              -- the first item, the length
  list[#list + 1] = "d"              -- add to the end
  local spawn = { x = 0, y = 64 }    -- named fields
  spawn.z = 0                        -- same as spawn["z"] = 0
  spawn.x = nil                      -- remove a field
  local mixed = { "a", count = 2, [10] = "ten", ["with space"] = true }
  local kills = {}
  kills[player] = (kills[player] or 0) + 1     -- anything but nil can be a key, even a player
  print(spawn.pos.x)                 -- tables in tables: one dot per step
  ```
  Two variables can hold the same table: changing it through one changes it for both.
  `value:offset(1, 0, 0)` with `:` calls a method on a value; it is short for `value.offset(value, 1, 0, 0)`.

  ## if
  ```
  if health >= 15 then
    print("healthy")
  elseif health >= 5 then             -- optional, as many as you like
    print("hurt")
  else                               -- optional
    print("help!")
  end
  ```

  ## Loops
  ```
  for count = 1, 10 do print(count) end      -- 10 times, count goes 1 to 10
  for count = 10, 1, -1 do print(count) end         -- count down (third number: the step)
  for index, player in ipairs(online_players()) do   -- each item of a list, in order
    print(index, player.name)
  end
  for key, value in pairs(spawn) do end      -- each field of a table, any order
  while count < 10 do count = count + 1 end        -- as long as true; checks before each round
  repeat count = count - 1 until count <= 0        -- until true; checks after: runs at least once
  ```
  - Forever is `while true do ... wait(1) ... end`: always wait inside, or the script is stopped.
  - `break` leaves the loop. `_` is a normal name, used for a value you don't need.
  - No `continue`: write `goto continue` and put `::continue::` right before the loop's `end`. `goto` jumps to any `::name::` in the same function.

  ## Functions
  ```
  local function add(first, second)         -- define
    return first + second                 -- give a value back and leave
  end
  local sum = add(2, 3)              -- use: 5
  local function two() return 1, 2 end
  local one, other = two()              -- several results at once
  local function all(...)            -- ... takes any number of values
    return select("#", ...), { ... } -- how many, and all of them as a list
  end
  local shout = function(text) return text:upper() end   -- a function without a name
  local util = {}
  function util.greet(player) end         -- stored in a table
  function util:hello() end          -- with ":" it gets the table as self
  print "hi"                         -- one text or one table: no ( ) needed
  ```
  - Missing arguments are `nil`, extra ones are dropped.
  - A function is a value: `on{ }`, `command{ }` and `run{ }` take one, usually written right there as `function(event) ... end`.
  - A function inside another still sees that one's local variables later.

  ## Basic functions
  - `print(first, second)`: writes to the server window. See [print( )](#print).
  - `type(value)`: Lua's sort of value: "nil", "number", "string", "boolean", "table", "function", "userdata", "thread". For Lullaby values use [type_of( )](#type_of).
  - `tostring(value)`, `tonumber("5")`: to text, to a number (`nil` when it isn't one; `tonumber("ff", 16)` reads other bases). See [tostring( )](#tostring).
  - `pairs(list)`, `ipairs(list)`, `next(list, key)`: go through a table (`next(list) == nil`: the table is empty). See [pairs( )](#pairs).
  - `select(number, ...)`: the values from that position on; `select("#", ...)` counts them.
  - `unpack(list)`: the items of a list as separate values: `math.max(unpack(list))`.
  - `assert(value, "text")`: stops with "text" when value is nil or false, else gives value back. The quick check.
  - `error("text")`: stops with a red error. `pcall(func, ...)` and `xpcall(func, handler, ...)` run func and catch errors. See [pcall( )](#pcall).
  - `load(text)`, `loadstring(text)`: turn text into a function to call; `nil` and the error when it isn't valid Lua.
  - `setmetatable(list, metatable)`, `getmetatable(list)`: change how a table acts (own classes, operators); most scripts never need it.
  - `rawget(list, key)`, `rawset(list, key, value)`, `rawequal(first, second)`: like `list[key]` and `==`, skipping the metatable.
  - `_VERSION`: the text "Lua 5.1".

  ## string: text
  All can be written `text:name(...)` too. Positions count from 1, negative ones from the end.
  - `text:len()` length · `text:upper()`, `text:lower()` · `text:rep(3, ", ")` repeat · `text:reverse()` backwards
  - `text:sub(2, 4)`: letters 2 to 4; `text:sub(-3)` the last 3.
  - `text:find("x")`: where x is (start, end), or nil. `text:find(".", 1, true)` searches plainly, without patterns.
  - `text:match("%d+")`: the first piece that fits the pattern. `text:gmatch("%a+")`: every piece, for a `for` loop.
  - `text:gsub("a", "b")`: replace every a with b; also gives the count.
  - `string.format("%d coins, %.1f%%, %s", 5, 2.25, "x")`: fill in. `%d` whole number, `%.2f` decimal, `%s` text, `%5d` padded, `%%` a %.
  - `text:byte(1)` letter to its code, `string.char(72, 105)` codes to text.
  - Patterns (find, match, gmatch, gsub): `%d` digit, `%a` letter, `%s` space, `%w` letter or digit, `.` anything, `[abc]` one of these, `*` `+` `-` `?` repeats, `^` start, `$` end, `( )` keep, `%` before a sign takes it as itself.
  - `string.dump(func)`: a function as bytecode text; `load` refuses it in Lullaby.

  ## table: lists
  - `table.insert(list, value)` add at the end · `table.insert(list, 1, value)` at the front
  - `table.remove(list)` take the last · `table.remove(list, 1)` the first; gives it back
  - `table.sort(list)` small to big · `table.sort(list, function(first, second) return first > second end)` your order
  - `table.concat(list, ", ")`: a list of texts as one text.
  - `table.move(from, 1, 3, 1, to)`: copy items 1 to 3 of from into to.
  - `table.maxn(list)`: the biggest number key. `table.getn`, `table.foreach`, `table.foreachi`: old, use `#list` and `for`.

  ## math
  - `math.random()` 0 to 1 · `math.random(6)` 1 to 6 · `math.random(5, 10)` 5 to 10 · `math.randomseed(number)` fixed order
  - `math.floor` down, `math.ceil` up; round with `math.floor(x + 0.5)`
  - `math.abs`, `math.min(...)`, `math.max(...)`, `math.sqrt`, `math.pow(number, power)`, `math.fmod(number, divisor)`, `math.modf(number)` (whole part and rest)
  - `math.sin`, `math.cos`, `math.tan`, `math.asin`, `math.acos`, `math.atan`, `math.atan2(y, x)`, `math.sinh`, `math.cosh`, `math.tanh`: in radians; `math.rad(degrees)`, `math.deg(radians)` convert.
  - `math.exp`, `math.log(number)` (natural), `math.log10`, `math.frexp`, `math.ldexp`
  - `math.pi` 3.14159…, `math.huge` bigger than any number

  ## coroutine and bit
  - `coroutine.create`, `resume`, `yield`, `status`, `wrap`, `running`, `isyieldable`: functions that pause and go on. In Lullaby, [wait( )](#wait) and [run{ }](#run) are simpler.
  - `bit.band`, `bor`, `bxor`, `bnot`, `lshift`, `rshift`, `arshift`, `rol`, `ror`, `bswap`, `tobit`, `tohex`: work on the bits of whole numbers.

  ## Locked
  For safety these don't exist in scripts; each can be unlocked in `config.lua` under `unlock`:
  - `io`, `dofile`, `loadfile` (io): files on the computer.
  - `os` (os): clock, programs, files.
  - `ffi` (ffi): raw memory.
  - `debug`, `jit`, `collectgarbage`, `gcinfo`, `getfenv`, `setfenv`, `newproxy` (debug): inside the shared Lua.
  - `require`, `module`, `package` (modules): C modules. For your own files use [import( )](#import).
expert: LuaJIT | Lullaby runs LuaJIT, which speaks Lua 5.1 plus goto. Newer Lua (//, bit operators like &, utf8, <const>) doesn't exist; bit.band and friends do. Numbers are doubles, whole numbers exact up to 2^53. # counts bytes: "ä" has length 2. Lua patterns (find, match, gsub) are not regex: %d digit, %a letter, %s space, % escapes, no | and no {n}.
expert: Isolation | every script file has its own globals and its own copy of string, table, math, coroutine and bit. getmetatable on a Lullaby value (player, vec3, ...) gives false, so no script can change how everyone's values behave. load and loadstring take Lua text only, never bytecode (broken bytecode can crash LuaJIT).
expert: Unlock | unlock.debug also brings jit, collectgarbage, gcinfo, getfenv, setfenv and newproxy: they reach into the Lua state all scripts share. unlock.java opens the [Java door](#java). config.lua is read again on /lullaby reload.
expert: Time limit | a loop running longer than script_time_limit (config) stops with a red error at its next call into the game (message{ }, player.name, ...); final still runs. A loop that never calls into the game (pure math) can't be stopped; after twice the limit the console names what is stuck. A loop that waits never hits the limit.
expert: Cost | arithmetic and one round of a compiled loop: about 1 ns (measured: 1,000,000,000 additions in 0.8–1.1 s). The time-limit check costs nothing per round. A new table or closure: guess 50–300 ns plus garbage collection (not measured). table.concat is the fast way to join many texts; .. in a loop is slow.

id: guide_waiting
name: Waiting and tasks
kind: guide
group: Guide
also: guide_memory
words: wait delay later seconds ticks task tasks run stop final schedule timer repeat every countdown cooldown save memory reload lost forever
lead: wait( ) pauses your code while the game goes on. Handlers and commands may wait; run{ } starts more.
text:
  ```
  local function countdown(player)
    for count = 3, 1, -1 do
      message{ player = player, text = tostring(count) }
      wait(1)                            -- 1 second; also "10t", "2s", "5m"
    end
  end
  command{ "go", function(context) run{ countdown, args = { context.player }, id = context.player } end }

  run{ function()                        -- every 2 seconds, forever
    while true do
      for _, player in ipairs(online_players()) do
        particle{ player = player, particle = "heart", pos = player.pos + vec3(0, 2.2, 0) }
      end
      wait("2s")
    end
  end }
  ```
  - `id =` allows one running task per id: a simple cooldown.
  - `final = function() ... end` runs whenever the task ends; `stop{ task = task }` ends one.
  - After a wait, check `player.online`.
  - Reload and restart run every file from the top again: variables reset and tasks end. Scripts can't save their own data yet.

--[[doc
id: guide_together
name: A mini game
kind: guide
group: Guide
words: example project minigame complete full script kill counter zombie hunt game round
lead: A 60-second zombie hunt, using every page before.
text:
  ```
  -- scripts/hunt.lua
  local running, score = false, {}

  local function tell_all(text)
    for _, player in ipairs(online_players()) do message{ player = player, text = text } end
  end

  local function round()
    running, score = true, {}
    tell_all("Zombie hunt! 60 seconds, go!")
    wait("60s")
    local best, most = nil, 0
    for player, count in pairs(score) do if count > most then best, most = player, count end end
    tell_all(best and (best.name .. " wins with " .. most) or "Nobody got a zombie")
  end

  command{ "hunt", function(context)
    if not running then run{ round, final = function() running = false end } end
  end, permission = "hunt.start" }

  after{ "EntityDeathEvent", function(event)
    if not running or event.entity_type ~= "zombie" then return end
    local killer = event.damage_source.causing
    if killer and type_of(killer) == "player" then score[killer] = (score[killer] or 0) + 1 end
  end }
  ```
  `final` resets `running` even after an error or reload. Not counting? `print(event.entity_type)` shows the real name.
  Try: skeletons for two points, `/hunt score`, a sound for the winner.

--[[doc
id: guide_worlds
name: Worlds and arenas
kind: guide
group: Guide
words: world worlds arena arenas map maps instance copy reset round void minigame template
lead: Build a map once, play in a fresh copy every round.
text:
  First make the map: `create_world{ id = "arena_map", generator = "void" }` once (a command is handy), build in it, then `unload_world{ world = "arena_map" }`. Keep it unloaded: only an unloaded world can be copied.
  ```
  -- scripts/arena.lua
  local function new_round()
    for _, world in ipairs(worlds()) do                -- the old round's arena, also after a restart
      if world.id == "minecraft:arena" then delete_world{ id = "arena" } end
    end
    copy_world{ from = "arena_map", to = "arena" } -- waits; the server keeps running
    local arena = load_world{ id = "arena" }
    for _, player in ipairs(online_players()) do
      teleport{ entity = player, location = location(arena, vec3(0.5, 65, 0.5)) }
    end
  end

  command{ "newround", function(context) new_round() end, permission = "arena.admin" }
  ```
  - `delete_world{ }` sends the players in the old arena to the main spawn first, then they come over to the new one.
  - Several arenas at once: name the copies `"arena_1"`, `"arena_2"`, ...
  - Worlds don't load again by themselves after a restart: load the ones you need when your script starts.
  ! Never let `delete_world{ }` reach your map: copy the map, delete only copies. A deleted world waits in `plugins/lullaby/temp` until the next server start, your last chance to move it back.
  More: [create_world{ }](#create_world), [copy_world{ }](#copy_world).
